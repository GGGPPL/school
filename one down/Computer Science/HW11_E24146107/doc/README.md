# HW10 RPG 遊戲系統實作說明

## 1. 遊戲特色與劇情
本遊戲整合了地圖探索與回合制戰鬥系統。
* **劇情背景**：玩家扮演勇者 Arthur 與法師 Merlin，進入「試煉之森 (Forest of Trials)」執行任務，必須在充滿迷霧的地圖中移動並擊敗潛伏的怪物。
* **探索系統**：具備 7x7 的視野系統 (Vision System)，地圖會隨玩家移動而滾動。
* **遭遇戰機制**：
    * **隨機遇敵**：在空地上移動時有 15% 的機率觸發戰鬥。
    * **座標遇敵**：踩到地圖上的 'M' 符號會觸發固定戰鬥。

## 2. 操作說明
* **W**: 向上移動
* **S**: 向下移動
* **A**: 向左移動
* **D**: 向右移動
* **Q**: 退出遊戲
* **戰鬥中**: 輸入 1 進行一般攻擊，2 使用特殊技能。

## 3. 地圖符號說明
* **P**: 玩家 (Player)
* **#**: 牆壁 (Wall) - 無法通行
* **M**: 怪物 (Monster) - 踩到會進入戰鬥
* **.**: 空地 (Floor) - 可能觸發隨機戰鬥


## 5. 類別整合說明
* **Field**: 負責載入地圖檔、處理 WASD 移動邏輯、碰撞偵測以及視野渲染。
* **Battle**: 當 Field 偵測到戰鬥觸發時，會傳入當前玩家狀態並初始化戰鬥。
* **Players/Monsters**: 沿用 HW9 的屬性與技能邏輯，戰鬥結束後會保留 EXP 與等級並反映回探索模式。
